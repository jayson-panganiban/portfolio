# Portfolio Dossier

Swiss-grid technical dossier portfolio built with Next.js, React, TypeScript, Tailwind CSS, and IBM Plex.

## Development

```bash
npm run dev
```

## Build

```bash
npm run build
npm run start
```

## Format

```bash
npm run format
```

Content lives in `data/`. Site configuration lives in `src/config/site.ts`.
